## Draft: Принципы и архитектура

- Ограничение: пока всё заточено под одного пользователя
- При добавлении хоста не должен изменяться `flake.nix`
- Пространство имён параметров всех моих nixos-модулей: `modules`
- Модули можно безопасно импортировать: конфигурирация в нём включается только через флаг `enable`
- Конфигурация, размещаемая в каталоге `hosts/_commons` применяется ко **всем** хостам
